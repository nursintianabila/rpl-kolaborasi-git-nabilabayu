Tentang Halo Sampit

Halo Sampit merupakan aplikasi web sederhana yang dibuat sebagai proyek pembelajaran kolaborasi Git.

Tujuan Aplikasi

Aplikasi ini bertujuan untuk mempelajari pengembangan web menggunakan Python Flask, pengelolaan branch, dan kolaborasi GitHub.

Teknologi yang Digunakan

  • Python
  • Flask
  • HTML
  • Git dan GitHub
